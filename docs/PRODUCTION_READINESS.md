## P1-01 原型视觉与交互对齐

### 导航与布局

- 常驻左栏断点为 1040px：`>=1040px` 使用 228px 左栏 + 342px 列表；收起为 52px 细条 + 360px 列表。`900–1039px` 使用抽屉 + 330px 列表；`761–899px` 为列表/详情单页切换。
- 展开态一级入口依次为时间线、收藏、音频、笔记，位于订阅树之前；无“工具”标题或分组留白。
- 搜索入口按状态唯一出现：展开态位于顶栏左格，52px 收起态位于细条，1040px 以下位于抽屉。
- 展开态顶栏左格为“读了么、搜索、收起边栏”；后两项右对齐、间距 2px，边栏开关右边缘与计数列对齐。
- “刷新订阅源”位于“我的订阅”标题右侧，图标 12px、热区 32px；订阅树末尾使用整行“添加”入口，菜单向上展开，新建文件夹插入到“添加”行之前。
- 文件夹默认 400 字重，仅选中时蓝色 700；设置固定在左栏底部，长订阅树不得改变其位置。

### 中栏

- 列表使用 40×40 缩略图和约 68–72px 行高；标题 13.5px/650/1.3，摘要 12px/1.35。
- 已读与未读保持相同文字、缩略图和透明度；仅未读显示蓝点。已读不保留点位占位，来源与标题首字对齐。
- 列表末尾只显示灰色常规字重“继续加载 30 天”，不显示历史未读数量。
- 收藏页只显示已收藏条目，计数由逐篇收藏状态实时推导；详情收藏状态与收藏页同步。
- 音频与笔记顶栏分别显示“音频 N 条”“笔记 N 条”，内容区不重复分组名、标题、数量或说明。搜索页不显示批量已读和排序。
- 顶栏全部操作只有一个槽位：音频为 `Eraser`“清空播放列表”，收藏为 `Eraser`“清空收藏”，笔记为 `Trash2`“删除全部笔记”。列表为空时禁用；点击即执行、显示成功反馈，不弹二次确认。

### 详情与图标

- 详情标题、副标题、播放器、标签和正文共享左边界；正文最大宽度 650px，字号 16px、行高约 1.75。
- 副标题来源与时间戳统一为 13px、灰色、400 字重，来源不加粗。
- 文章和播客首个标签统一为“正文”及相同图标；AI 摘要直接显示短精华，深度精华默认收起并由居中按钮展开。
- 正文、AI 摘要、逐字稿、笔记 Tab 图标以 15px 可见尺寸为基准；逐字稿使用标准 Lucide `AudioLines`。点击热区不得随图标缩小。
- 详情操作固定在右栏顶栏右侧，使用横向五项胶囊：标记已读/未读、收藏、打开原文、阅读设置、沉浸阅读。阅读设置面板从顶栏下方展开并与胶囊右边缘对齐。
- 设置使用居中弹窗，不替换三栏上下文；关闭后焦点返回触发入口。

### Tooltip

- 纯图标控件使用统一的页面内 tooltip，不能依赖原生 `title`；位置须限制在视口内，不能被滚动容器裁切。
- 有可见文字的导航、订阅树和文章行不重复显示 tooltip。
- 52px 收起细条隐藏文字后，为时间线、收藏、音频、笔记、搜索、设置显示名称；边栏开关按状态显示“展开边栏/收起边栏”。

## P1-02 移动端

- 底部导航为时间线、搜索、收藏、更多；抽屉包含完整导航和设置。
- 详情正文使用 16–17px，并验证 390px、短屏、横屏、软键盘和安全区。

## P1-03 无障碍与键盘

- 所有图标按钮有准确的动态 `aria-label`、可见焦点和匹配当前状态的 tooltip。
- 桌面热区不少于 32px，移动主要操作不少于 44px。
- 播放进度支持方向键、Home 和 End；弹窗和抽屉约束焦点，关闭后返回触发点，Escape 行为可预测。
- 小字号辅助文字、选中态和已读态满足 WCAG AA。
