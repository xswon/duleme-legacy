读了么

一个本地优先的 RSS 阅读器。订阅、阅读、收藏、笔记和播客集中在一个应用里；AI 与转录按需开启，不影响基础阅读体验。

下载 macOS 公测版
当前 macOS 公测版暂未经过 Apple Developer ID 签名。首次打开时如果被系统阻止，请前往“系统设置 → 隐私与安全性 → 仍要打开”。
Desktop V0.1 · macOS 优先 · 数据默认保存在本地

V1

  • 无需 Node、Docker 或命令行即可使用桌面版。
  • 支持精选订阅、手动添加 RSS 与 OPML 导入。
  • 支持阅读状态、收藏、笔记、搜索、播客播放和本地备份。
  • AI 与转录使用自己的 API，可完全不配置。
