# 原型到生产版实施记录

最后更新：2026-09-15

用户确认以 `docs/prototypes/netnewswire-ui/` 的 `index.html`、`styles.css`、`prototype.js`（当前 `?v=20`）为唯一视觉基准；旧预览 PNG 与旧设计文档发生冲突时不采用旧值。生产实现复用真实数据、错误处理和持久化能力，不复制原型的评审控制条与静态假数据。

## 已确认约束

- 逐项复用字体、字号、字重、行高、字距、颜色、图标路径与描边、尺寸、内外边距、间距、圆角、背景、边框和阴影。
- 真实业务、存储、路由和单一音频控制器继续复用，不进入原型改动的范围。
- 不自行设计缺失状态；视觉冲突或未知状态须由用户确认后实施。
- 桌面列表标题 13.5px / 650 / 1.3，摘要 12px / 1.35，缩略图 40px；已读与未读保持相同视觉权重，仅未读显示小蓝点，已读来源不保留点位占位并与标题左对齐。
- 左栏展开态一级入口为时间线、收藏、音频、笔记，无“工具”标题或额外留白；文件夹默认 400 字重，选中时蓝色 700。
- 搜索入口随状态变化：展开态在顶栏左格，52px 收起细条用图标入口，1040px 以下用抽屉，任意时刻只出现一个。
- 展开态顶栏左格为“读了么”、“搜索”、“收起边栏”，后两者右对齐、间距 2px；“刷新订阅源”在“我的订阅”标题右侧；“添加”在订阅树末尾的整行入口、菜单向上展开。
- 详情副标题来源与时间戳统一为 13px 灰色 400；详情 Tab 图标以 15px 可见尺寸为基准，逐字稿使用标准 Lucide `AudioLines`。
- 音频与笔记数量只显示在中栏顶栏标题后；音频/收藏使用 `Eraser` 清空，笔记使用 `Trash2` 删除全部，均点击即执行并反馈，不弹确认。搜索页不显示批量已读和排序。
- 收藏按文章状态筛选并实时更新计数；纯图标使用自绘 tooltip，有文字入口不重复提示，52px 收起细条为隐藏标签补充提示。
- 断点：常驻侧栏为 1040px，常规列宽 228px + 342px；收起为 52px + 360px；900–1039px 为 330px 列表与详情。
- 设置形态为居中弹窗；阅读详情操作使用顶部横向 `reader-actions`，播放器统一复用 `player-*` 控件。

## 实施边界

- 添加订阅的完整界面没有独立原型；用户确认保留生产版既有样式。
- 顶部横向阅读操作栏在窄栏沿用同组尺寸、颜色与间距。
- 旧预览图和历史测试记录不视为本轮生产验收；以当前原型和 `PRODUCTION_READINESS.md` 为准。

- 自动化验证：TypeScript 检查、39 个测试文件共 261 项测试、生产构建和差异卫生检查通过。
