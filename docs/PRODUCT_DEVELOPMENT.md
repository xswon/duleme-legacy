# 读了么产品开发说明

## 1. 产品定位

读了么是一款本地优先、单用户的 RSS 阅读与播客整理工具。当前版本优先保证用户在一台设备上的订阅、阅读、收藏、笔记、播放和 AI 整理流程稳定可用；账户体系、多人使用和跨设备云同步不属于当前版本范围。

本地优先不等于数据可丢失。业务数据以 IndexedDB 为主存储，设置页提供带版本与校验信息的完整备份和恢复；OPML 继续用于订阅清单的导入导出，但不替代完整备份。

## 2. 核心用户任务

1. 添加或导入订阅，并用文件夹组织订阅源。
2. 在时间线、收藏、文件夹和单个订阅源范围内浏览文章，并可在时间线中仅看未读。
3. 阅读文章，标记已读/未读、收藏、打开原文或进入沉浸阅读。
4. 播放播客、维护播放列表并恢复播放进度。
5. 搜索本地文章，在文章正文、摘要、来源和作者中定位内容。
6. 对播客和文章生成或查看整理内容、逐字稿与笔记。
7. 导出或恢复本地数据。

## 3. 信息架构与路由

路径表示当前工作范围，文章详情和筛选作为查询参数合并在范围上：

| 入口 | URL |
| --- | --- |
| 时间线 | `/today` |
| 时间线 · 仅看未读 | `/today?unread=1` |
| 时间线 · 内容类型 | `/today?type=article|podcast`；全部类型时省略 |
| 时间线 · 历史窗口 | `/today?days=60|90|…`；最近 30 天时省略 |
| 收藏 | `/starred` |
| 订阅源 | `/feed/:feedId` |
| 文件夹 | `/folder/:folderId` |
| 音频 | `/playlist` |
| 笔记 | `/notes` |
| 搜索 | `/search?q=` |
| 设置 | `/settings` |
| 文章详情 | 当前路径合并 `article=:articleId` |
| 详情标签 | 当前查询参数合并 `tab=body|ai|transcript|notes`；深度精华是 `ai` 内部展开态，不单独占用 URL 标签 |

筛选参数同样适用于订阅源和文件夹路径，并与 `article`、`tab` 合并。浏览器刷新必须恢复范围、筛选、已加载天数、搜索词、文章和详情标签。浏览器返回先关闭文章详情，再离开当前范围。抽屉、Toast、菜单展开、焦点和播放进度等临时状态不进入 URL。无效订阅源、文件夹或文章 ID 必须显示可恢复的空状态。

现有 `/unread` 作为兼容路由重定向到 `/today?unread=1`，不再出现在主导航中。

## 4. 功能和业务规则

### 4.1 订阅与同步

- 同一时间只允许一个全局刷新任务。
- 每个订阅源独立记录刷新状态；一次刷新可以整体成功、部分失败或整体失败。
- 成功订阅源的数据正常落库，不能因其他订阅源失败而回滚。
- 失败提示保持到用户关闭或重试成功；单源重试不得触发全量刷新。
- 刷新过程中删除订阅源后，忽略该订阅源迟到的响应。
- OPML 导入报告实际新增、重复和无效数量，并只刷新实际新增的订阅源。
- 删除文件夹时保留其中订阅源，并移动到“未分类”。

### 4.2 阅读

- 选中另一篇文章只更新详情，不改变当前范围。
- 文章和播客详情的第一个标签统一为“正文”并使用同一图标；AI 摘要直接展示短精华，深度精华默认收起并由居中按钮按需展开。
- 桌面三栏中，左栏一级入口为时间线、收藏、音频、笔记，位于订阅树之前；不显示“工具”标题，也不保留分组留白。
- 搜索不作为固定一级入口：展开态由顶栏左格承接，52px 收起细条保留搜索图标，1040px 以下由抽屉承接，任意时刻只有一个可点的搜索入口。
- 展开态顶栏左格固定为“读了么”、“搜索”、“收起边栏”三项，后两者右对齐、间距 2px；“刷新订阅源”位于“我的订阅”标题右侧并触发全局刷新；添加订阅源/文件夹位于订阅树末尾的整行“添加”入口，菜单向上展开。
- 左栏底部“设置”始终固定在侧栏底部同一位置，订阅内容过长时不得挤压或移动底部操作区；52px 收起细条和抽屉保持相同顺序与层级。
- 文件夹名称默认使用 400 字重，仅选中时使用与其他左栏选中项一致的蓝色和 700 字重。
- 右栏文章标题与左栏导航、中栏内容区使用同一条 9px 顶部起始轴；副标题、播放器、标签和正文随文章容器整体排列，不用额外位移制造视觉对齐。副标题中的来源与时间戳统一为 13px、灰色、400 字重，来源不得加粗。
- 桌面文章快捷操作固定在右栏顶栏右侧，采用横向胶囊，自左至右包含标记已读/未读、收藏、打开原文、阅读设置和沉浸阅读；顶栏位于滚动容器之外，不得覆盖 650px 正文版心。阅读设置面板从顶栏下方展开并与胶囊右边缘对齐。
- 761–899px 单页模式沿用同一枚顶栏横向胶囊，并隐藏中栏时间线工具条；移动端沿用详情页内操作区。
- 时间线和单个订阅源默认查询用户本地时区最近 30 个自然日，即从本地日期往前 29 天的零点到当前时刻；继续加载时每次向前扩展 30 天。
- 左栏时间线计数始终只统计最近 30 天内全部订阅源的未读文章，并以 `99+` 封顶；加载更早内容不得改变该计数口径。
- 日期跨过本地零点后，超出 30 天窗口的未读会自然退出计数；这是窗口语义，不得误报为已读状态变化。
- 页面长时间打开时，应在下一个本地零点或重新获得可见性后刷新日期窗口与计数。
- 订阅源列表中的未读计数默认采用相同的最近 30 天口径，避免同一界面出现两套未声明的数字定义。
- 中栏已读项不显示蓝点，也不保留蓝点占位；来源左移并与标题首字对齐。已读与未读的其他文字、缩略图和透明度保持一致。
- 列表末尾只显示灰色常规字重的“继续加载 30 天”，不展示更早未读数量；最近 30 天为零不等于全部历史已读。
- 扩展历史范围后，列表顶部以同款轻量控件提供“收起至最近 30 天”，不显示独立状态条或分隔线。
- 批量标为已读只处理点击时当前已加载时间范围和当前筛选结果，并提供 5 秒撤销。全历史标为已读必须放在更多菜单中并二次确认。
- 阅读、收藏、笔记和阅读进度的持久化失败必须回滚或显示可操作错误。
- 文章刷新后 ID 改变时，已读、收藏、笔记、播放列表和播放进度引用必须迁移。
- 收藏按文章逐条存储；收藏页默认显示全部历史收藏，不受时间线 30 天窗口限制，并通过虚拟化列表控制渲染开销。左栏与抽屉计数实时取当前收藏数，详情页切换收藏状态后立即同步。

### 4.3 音频

- 全应用共享一个音频控制器，同一时间只有一个音频实例播放；文章详情、播放列表和队列行不得各自创建互不协调的播放状态。
- 播放按钮只播放或暂停；点击标题或封面才打开文章详情。
- 正在播放、暂停选中和右栏正在查看是三个可区分状态。
- 详情和播放列表共享进度、错误与倍速；倍速支持 `0.75x`、`1x`、`1.25x`、`1.5x` 和 `2x`，切换视图后保持一致。
- 进度区左侧显示当前时间，右侧显示媒体的具体结束时间，不显示概略分钟数。
- 删除当前播放项会停止播放并选中下一项，但不自动播放。
- 页面刷新恢复节目和进度，但不自动开始播放。
- 音频中栏顶栏显示“音频 N 条”，数量紧跟标题；右侧 `Eraser` 用于清空播放列表，内容区不重复标题或数量。清空点击即执行并反馈结果，不弹二次确认。

### 4.4 笔记与搜索

- 笔记中栏顶栏显示“笔记 N 条”，数量紧跟标题；右侧 `Trash2` 用于删除全部，点击即执行并反馈结果，不弹二次确认。内容区直接显示笔记列表或空状态，不重复“工具”、标题、数量或说明文案。
- 搜索中栏顶栏不显示批量标为已读和排序操作；搜索框固定在结果列表上方。

### 4.5 AI 与本地整理

- 任务状态为 `not_started`、`processing`、`completed` 或 `failed`。
- 同一文章的同类任务处理中不得重复创建。
- 切换文章不取消后台任务；失败保留原因与重试入口。
- 已有结果重新生成时不得静默覆盖。
- 本地整理服务不可用与远端模型请求失败应提供不同反馈。
- 详情标签统一采用相同视觉重量的 Lucide 风格图标，正文、AI 摘要、逐字稿和笔记以 15px 可见尺寸为基准；逐字稿使用标准 `AudioLines` 音波竖线图标。

### 4.6 操作提示

- 纯图标按钮使用统一的页面内 tooltip，位置限制在视口内；不依赖浏览器原生 `title`。
- 已显示文字的导航、订阅树和文章行不重复提示；52px 收起细条隐藏文字后，为时间线、收藏、音频、笔记、搜索和设置显示名称提示。

## 5. 数据边界

- IndexedDB：订阅源、文章、阅读/收藏状态、笔记、文件夹顺序、播放列表、音频进度。
- localStorage：排序、界面偏好和迁移标记等可丢失数据。
- 旧数据迁移必须幂等，写入并回读验证成功后才删除旧值。
- 完整备份必须带格式版本和校验值；恢复前验证结构与校验值。

## 6. 当前版本非目标

- 用户注册、登录和权限系统。
- 云端同步、共享阅读列表和多人协作。
- 服务端全文索引、推荐算法和社交功能。
- 面向公网开放无认证的 RSS、媒体或 AI 代理。

## 7. 发布验收

- 发布状态和逐项验收以 `docs/PRODUCTION_READINESS.md` 为准；五项 P0 已于 2026-09-14 完成，正式发布前继续完成其中列出的 P1 与候选版本回归。
- TypeScript 检查、自动化测试和生产构建通过。
- 真实浏览器验证 URL 恢复、前进/后退和无效 ID。
- 在 390、760、899、900、1039、1040 和 1440px 宽度验证布局。
- 逐项切换已选文章、空详情、订阅源、普通文章、音频、笔记、搜索和设置，确认左栏导航层级、无“工具”标题及“设置”底部坐标不变；分别验证展开边栏、52px 细条、抽屉及长订阅树，并确认搜索入口在各状态下只出现一次。
- 验证已读来源与标题左对齐、文件夹 400/700 字重切换、详情来源与时间戳样式一致、音频/收藏使用 `Eraser`、笔记使用 `Trash2` 且点击即执行、搜索页无批量已读和排序操作，以及详情标签图标的视觉尺寸一致。
- 验证纯图标 tooltip 不被滚动容器裁切；有文字入口不重复提示，52px 收起细条能显示各入口名称。
- 验证展开态顶栏左格三项落点不重叠（“收起边栏”右边缘对齐订阅树计数列）、“我的订阅”标题右侧刷新图标与标题同排且不压标题、订阅树末尾“添加”行不遮挡新增文件夹且菜单向上展开不越界。
- 在文章详情验证顶栏右侧横向胶囊不遮挡内容、滚动时位置稳定，阅读设置面板与胶囊右边缘对齐且不越界；单页和移动端正确回退。
- 验证 OPML 部分成功、同步部分失败、图片失败、音频失败和 AI 失败。
- 验证键盘操作、可见焦点、移动安全区和主要控件触控热区。
- 完整备份导出后可在空数据环境中恢复，并通过数量和校验验证。
